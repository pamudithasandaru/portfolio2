# Portfolio Client

React 19 + Vite frontend. See the [root README](../README.md) for setup, scripts, environment variables and deployment notes.

```bash
npm install
npm run dev
```

The admin panel lives in `src/admin/` and is served at `/admin` (lazy-loaded, so visitors never download it). Page text defaults are in `src/content/siteDefaults.js`; blog posts come from the API.
